# Logos dos projetos

Coloque aqui os arquivos de logo de cada projeto.

| Projeto   | Nomes aceitos (sem extensão)     |
|-----------|----------------------------------|
| Polygonus | `polygonus_logo` ou `polygonus`  |
| Anihype   | `anihype_logo` ou `anihype`      |

Extensões aceitas (a app tenta nesta ordem): `.png`, `.svg`, `.webp`, `.jpg`, `.jpeg`.

Exemplos válidos:

- `polygonus_logo.png` ou `polygonus.png`
- `anihype_logo.svg`

A app tenta automaticamente variações do nome (`polygonus` ↔ `polygonus_logo`).

Upload pela interface virá em uma fase futura — por enquanto, basta copiar os arquivos para esta pasta e recarregar a página.
